# Source notes

This skill synthesizes and adapts ideas from these public projects:

- [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman), MIT License — concise, substance-preserving agent communication.
- [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill), MIT License — anti-template frontend judgment and brief inference.
- [pbakaus/impeccable](https://github.com/pbakaus/impeccable), Apache License 2.0 — product/brand registers, design-system alignment, and systematic polish.
- [kylezantos/design-motion-principles](https://github.com/kylezantos/design-motion-principles), MIT License — context-aware motion, frequency gating, accessibility, and performance.
- [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser), Apache License 2.0 — browser automation workflow discovery and accessibility-tree verification.

The workflow and wording in this skill are a new synthesis rather than a verbatim bundle of the source skills. Consult the upstream repositories for their complete current instructions and licenses.
